# Política de Seguridad — VetCare Pro

## Versiones Soportadas

| Versión | Soportada |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reportar una Vulnerabilidad

Si descubres una vulnerabilidad de seguridad en VetCare Pro, por favor **no la reportes públicamente en GitHub Issues**.

En su lugar, envía un correo electrónico detallado a `security@vetcarepro.com` con:

- Descripción del hallazgo y potencial impacto.
- Pasos detallados para reproducir el problema o PoC.
- Componente afectado (Backend API, Frontend, Base de Datos, CI/CD).

Agradecemos tus aportes para mantener el sistema seguro.
