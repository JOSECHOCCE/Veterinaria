📋 FLUJO 3 — Ciclo de Vida de una Cita (EL FLUJO CENTRAL)

Según Requerimientos (RF-18 a RF-25)

Este es el corazón del sistema. El flujo completo es:

stateDiagram-v2 [*] --> Pendiente: Cliente solicita cita Pendiente --> Confirmada: Recepcionista confirma Confirmada --> EnEspera: Cliente llega a clínica EnEspera --> EnAtencion: Veterinario inicia consulta EnAtencion --> Completada: Veterinario cierra atención Pendiente --> Cancelada: Cualquiera cancela Confirmada --> Cancelada: Cancela (>2h antes) Confirmada --> NoAsistio: Cliente no llega Completada --> [*] Cancelada --> [*] NoAsistio --> [*]

Flujo Paso a Paso

sequenceDiagram participant C as 👤 Cliente participant S as 🌐 Sistema participant R as 🖥️ Recepcionista participant V as 🩺 Veterinario Note over C,S: PASO 1 — Solicitar Cita (RF-20, RF-43) C->>S: Selecciona mascota → servicio → fecha → hora S->>S: Valida disponibilidad (RF-21) S->>S: Estado = "Pendiente" S->>R: 🔔 Notificación: nueva cita solicitada Note over R,S: PASO 2 — Confirmar Cita (RF-22) R->>S: Confirma la cita S->>S: Estado = "Confirmada" S->>C: 🔔 Notificación: tu cita fue confirmada Note over S: PASO 2.5 — Recordatorio (RF-38) S->>C: 📧 Recordatorio 24h antes de la cita Note over C,V: PASO 3 — Día de la Cita C->>R: Llega a la clínica R->>S: Registra llegada (Estado = "En espera") Note over V,S: PASO 4 — Atención Clínica (RF-26) V->>S: Selecciona cita → Inicia atención S->>S: Estado = "En atención" V->>S: Registra signos vitales (RF-27) V->>S: Registra historia clínica (RF-28) V->>S: Cierra atención (RF-29) S->>S: Estado = "Completada" S->>C: 🔔 Notificación: mascota lista para recoger Note over R,S: PASO 5 — Cobro (RF-31) R->>S: Registra cobro (monto, método de pago) S->>S: EstadoPago = "Pagado" S->>C: 📄 Comprobante PDF disponible
