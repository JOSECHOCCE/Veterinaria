## Spec-Driven Development (SDD) Phases

- `sdd-init`: Initialize SDD context, testing capabilities, registry, and persistence.
- `sdd-explore`: Deep dive exploration of existing repository codebase.
- `sdd-propose`: High-level feature proposal and architectural alignment.
- `sdd-spec`: Technical specification and contract definition.
- `sdd-design`: System and component architecture design.
- `sdd-tasks`: Actionable implementation task breakdown.
- `sdd-apply`: Code change implementation phase.
- `sdd-verify`: Verification and test suite execution.
- `sdd-archive`: Complete change archival and finalization.
- `sdd-onboard`: Project context onboarding.
